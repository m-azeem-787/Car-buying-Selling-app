# Wheel Deal - Car Buying & Selling App

Wheel Deal is a Flutter-based car buying and selling application that allows users to browse cars, list their own vehicles, and manage bookings using Firebase services.

---

## Features

- User Authentication
- Browse available cars
- View detailed car information
- List cars for sale
- Manage user profile
- View listed cars
- Book cars
- Firebase integration for backend services

---

## Tech Stack

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- GoRouter
